# ML Prediction Service

Учебный проект по дисциплине DevOps-инженерия.

## Описание

ML Prediction Service — сервис для получения
предсказаний с использованием модели машинного обучения.

## Технологии

- Python
- Flask
- PostgreSQL
- Git
- Docker
- Ansible
- Terraform
- Prometheus
- Grafana

## Структура проекта

- app/ — приложение и конфигурация
- model/ — обучение и загрузка ML-модели
- db/ — скрипты базы данных
- docker/ — контейнеризация
- ci/ — непрерывная интеграция
- ansible/ — автоматизация настройки
- terraform/ — инфраструктура
- monitoring/ — мониторинг

## Статус

Лабораторная работа №2.
Создание структуры проекта и настройка Git.
Проект развивается в рамках дисциплины «DevOps инженерия».
